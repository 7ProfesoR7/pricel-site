# Лендинг «Прицел» (pricel-ai.ru)

Технический контекст проекта. Глобальный Устав пользователя главнее.

## Что это
Одностраничный лендинг продукта «Прицел · Замеры»: ИИ разбирает звонки компаний ремонта и стройки и показывает клиентов, которым обещали перезвонить или назначить замер, а следа в CRM нет. Документация продукта: `C:\Users\User\Workspace\Obsidian\Проекты\Прицел\` (старт — `00_Обзор.md`, тексты — `12_Шаблоны_сообщений.md`).

## Цель страницы
Одно действие: заявка на бесплатный разбор 10 звонков (кнопка «Написать в Telegram»). Режим Impeccable — Persuade.

## Жёсткие правила
- Чистый HTML + CSS (+ минимум JS), без сборщиков и фреймворков. Хостинг — GitHub Pages из ветки `main`, папка `/docs`. Публикуется только `docs/`; служебные файлы (CLAUDE.md, `.claude`, `refs`) лежат в корне и на сайт не попадают.
- Шрифты только с кириллицей и только локально в `assets/fonts` (без Google Fonts и внешних CDN). Не использовать Inter, Roboto, Open Sans, Lato, Arial.
- Без форм сбора данных, без внешних счётчиков и трекеров (152-ФЗ). Контакты — ссылки Telegram и телефон.
- Бренд: чёрно-оранжевый (решение 22.11.2026). Тёплый чёрный `#0B0A09` / `#14120F` / `#201C18`, светлый текст `#EDE8E1`, оранжевые оттенки от `#FF6B00` (основной) через `#FF9A3C` до `#FFB547`, глубокий `#B3470A`; красный `#FF4A3D` — только отметка «в CRM пусто». Значок — перекрестие с узлом нейросети (см. `Obsidian\Проекты\Прицел\13_Материалы\01_Бренд\Бренд_Прицел.md`). Сайт тёмный по умолчанию.
- Промпт сборки лендинга: `prompts/landing_build_prompt.md` — читать перед любой работой над страницей.
- Не обещать цифр результата («вернём 30%»). Пример отчёта — только учебный, с вымышленными данными.
- Одна «вау»-сцена на страницу (живая строка отчёта), остальное спокойно.
- Проверка: мобильная ширина 375 px, клавиатурный фокус, `prefers-reduced-motion`.

## Скиллы проекта (`.claude/skills`)
- `landing-page-design` — структура лендинга под одно действие, копирайтинг, визуальные правила.
- `frontend-design` (Anthropic) — дизайн-план до кода, анти-шаблонность.
- `impeccable` — критика и полировка (`critique`, `polish`, `typeset`, `layout`). Установлен без папки `scripts`: лаунчер не запускать, работать по разделу «Launcher unavailable».
- `emil-design-eng`, `animate` (Emil Kowalski) — компоненты и выверенная анимация.
